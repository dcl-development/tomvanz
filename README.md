# tomvanz.com

One Next.js app. The map is `/`. Tom edits at `/studio`.

## Local

```bash
cd web && npm install && npm run dev
```

- Site: http://localhost:3000
- Studio: http://localhost:3000/studio

Copy `.env.example` to `.env.local` if you want a read token. Project id and dataset are already public defaults.

## Tom

Invite him as Editor in [sanity.io/manage](https://www.sanity.io/manage). He opens `/studio`, publishes, and drafts stay off the map.
